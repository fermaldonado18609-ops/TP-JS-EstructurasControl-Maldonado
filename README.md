Repositorio correspondiente al Trabajo Práctico de **Entrada de Datos y Estructuras de Control** desarrollado en JavaScript (ES6+). El proyecto aborda la captura de datos mediante `prompt()`, la evaluación de reglas de negocio con estructuras condicionales (`if`, `else if`, `else`, `switch`) y la salida de resultados a través de `alert()` y `console.log()`.
